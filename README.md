# Agenda de Oradores — instaladores e atualizações

Este repositório guarda só os instaladores e o manifesto assinado das atualizações da Agenda de Oradores. O código não fica aqui.

- **Instalar:** baixe a versão mais recente em [Releases](../../releases/latest). Use o `.dmg` no Mac e o `setup.exe` no Windows.
- **Atualizações:** o app consulta `atualizacao.json` e só aceita versões assinadas com a chave da Agenda de Oradores.
